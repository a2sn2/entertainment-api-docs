A

نسخة GitHub Pages

تعمل مجانًا بالكامل داخل المتصفح. البيانات تجريبية ومحلية لجهاز الزائر، ولا توجد SQL Server أو Identity حقيقية.

  • محاكاة المستخدم والإدارة.
  • حفظ البيانات في localStorage.
  • مناسبة للعرض السريع والمحفظة المهنية.
B

نسخة جهازك

هي المنتج الحقيقي: Blazor WebAssembly وASP.NET Core API وIdentity وEF Core وSQL Server وسجل تدقيق.

  • تشغيل بضغطة عبر START-ATHAR.cmd.
  • قاعدة بيانات دائمة داخل Docker Volume.
  • إمكانية العرض داخل الشبكة أو عبر Tunnel مؤقت.
C

نفس قصة المنتج

النسختان تعرضان التدفق نفسه: إنشاء مبادرة، مراجعة إدارية، قرار، ثم ظهور النتيجة للمستخدم.

  • User Full Stack.
  • Admin Full Stack.
  • Workflow Boundary واضح.
أثَر · تجربة مجانية مبنية على FoundationKit لا تدخل بيانات حقيقية أو حساسة في هذه النسخة.
