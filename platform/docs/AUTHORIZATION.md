# Authorization Matrix

| Capability | Administrator | Editor | Reviewer | Reader |
|---|---:|---:|---:|---:|
| View published documentation | Yes | Yes | Yes | Yes |
| Create document | Yes | Yes | No | No |
| Add version | Yes | Yes | No | No |
| Submit for review | Yes | Yes | No | No |
| Publish reviewed version | Yes | No | Yes | No |
| Archive document | Yes | No | Yes | No |
| Manage users and roles | Yes | No | No | No |
| Manage platform settings | Yes | No | No | No |

Authorization is enforced in the API, not only hidden in the UI.
