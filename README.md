# Entertainment Services API Documentation

Interactive documentation portal for the Entertainment Services API.

- **Document reference:** API-ENT-DOC-001
- **Version:** 1.0
- **Environment:** Test
- **Classification:** Internal Integration Use

## Live documentation

After GitHub Pages is enabled, the site is available at:

https://a2sn2.github.io/entertainment-api-docs/

## Local use

Open `index.html` in a modern browser. The published site uses local `styles.css` and `app.js` files and makes no live API calls.

## Security notice

The repository is public. Do not add credentials, access tokens, production URLs, personal data, or internal secrets.
