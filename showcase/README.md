# FoundationKit Showcase

The Showcase is the runnable public experience at the repository root. It is deliberately separate from the FoundationKit packages.

## Entry points

- `index.html`
- `assets/css/showcase.css`
- `src/showcase.js`
- `manifest.webmanifest`
- `sw.js`

## Behavior

1. Ask the visitor: “What do you want to build today?”
2. Analyze the text locally in the browser.
3. Classify the idea into a broad product category.
4. Present an initial map for Domain, Application, API & Security, Data, Experience, and Quality.
5. Let the visitor copy the summary.
6. Offer a public GitHub project-inquiry form.

The entered idea is not sent to a backend automatically.

## Contact configuration

The current public contact path uses:

- GitHub profile: `https://github.com/a2sn2`
- repository issue form: `.github/ISSUE_TEMPLATE/project-idea.yml`

The issue form is public. Visitors are explicitly warned not to post confidential information. Private contact links can be added later only after the exact approved URLs or email address are available.
